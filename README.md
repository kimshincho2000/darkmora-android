# DarkMora Native Android App 📱✨

DarkMora — Zamonaviy va rasmiy Android Anime striming ilovasi.

## Texnologik stek:
- **Til:** 100% Native Kotlin (2.0+)
- **UI:** Jetpack Compose + Material 3 (Material You, Glassmorphism)
- **Arxitektura:** Clean Architecture / MVVM, Coroutines & Flow
- **Pleyer:** AndroidX Media3 (ExoPlayer) HLS/m3u8 va MP4 striming
- **Tarmoq:** OkHttp & Gson (to'g'ridan-to'g'ri `https://darkmora.uz/api`)
- **Rasmlar:** Coil Compose kesh va tezkor yuklash
- **Hajmi:** ~18-20 MB (o'ta yengil va 120 Gts silliq)

## Xususiyatlari:
- 🎬 Katta Hero Premyera karuseli
- 🔥 Trenddagi, yangi va reytingi baland animelar
- 📚 Janrlar bo'yicha filter va tezkor qidiruv
- 📺 Silliq kino-pleyeri (avto-landscape, orqaga/oldinga 10s, qismlar menyusi)
- ⭐️ Sevimlilar ro'yxati
